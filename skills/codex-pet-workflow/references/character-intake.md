# Character Intake

Use this reference before turning an arbitrary image into a Codex pet.

## Suitability Check

Accept an input image when it has enough visual information to preserve identity in small animated cells:

- Clear character silhouette and readable full or near-full body proportions.
- Face, hair, outfit, and at least one signature detail are visible.
- The pose is not so cropped, occluded, dark, or blurred that key anchors are guessed.
- The user has rights or permission to use the character as a local pet.

If the image is weak, ask for one better reference or create a first-pass design proposal before committing to animation.

## Identity Anchors

Write a short character lock before drawing frames:

- **Role**: e.g. half-elf companion, robot mascot, plush creature, office assistant.
- **Silhouette**: head/body ratio, hair outline, clothing volume, ears/tail/wings/tools.
- **Face**: eye shape, expression range, face markings, glasses, blush, mouth style.
- **Palette**: base colors, accent colors, glow colors, what must not change.
- **Outfit/accessory**: one to three details that identify the character at tiny sizes.
- **Motion temperament**: quiet, bouncy, sleepy, proud, shy, elegant, chaotic, etc.

## Confirmation Preview

Before full production, make one of:

- A single cleaned idle frame.
- A 2x2 mini sheet with idle, walk, wave, and tired/damaged concept.
- A small model card with front view, palette swatches, and accessory detail.

Ask for confirmation in plain terms: "Is this still the same character?" and "Which details are wrong?" Only move to the full atlas after the user confirms or gives precise corrections.

## Redraw Discipline

When identity is wrong, redraw the frame or regenerate with stronger anchors. Do not rely on simple brightness, blur, scaling, or color overlays to simulate a new form. Those tricks are acceptable only for temporary logic tests, never for final state art.
